# Sistema de Reservas de Salas de Estudo

Projeto desenvolvido em **C#** como parte da disciplina de **Programação Orientada a Objetos**.

Este sistema permite configurar datas e horários válidos para reservas e registrar salas de estudo com validações completas.

---

## Objetivo

Aplicar conceitos fundamentais de **POO - Programação Orientada a Objetos**, como:

- Abstração
- Encapsulamento
- Validação de dados
- Separação de responsabilidades

---

## Funcionalidades

- Cadastro de configuração da reserva:
  - Data mínima e máxima
  - Hora mínima e máxima

- Registro de reserva com:
  - Data e hora da reserva
  - Descrição da sala
  - Capacidade (entre 1 e 39)

- Validações automáticas:
  - Datas e horários dentro do período permitido
  - Capacidade válida
  - Exibição de mensagens de erro acumuladas

- Exibição formatada das informações da reserva
